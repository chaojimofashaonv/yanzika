播放

这不是本站自带的功能。本站没有语音合成引擎、也没有后端或代你配音的服务：MiniMax 语音只是接入第三方「MiniMax 开放平台」的一条通道——要你自己有 MiniMax 账号并填 API Key，能不能念、念成什么样、扣多少额度都由 MiniMax 那边决定，与本站作者无关；这也是全站少数会把内容发到你设备之外的地方（你点哪一句、那句的文字就会传给 MiniMax 服务器）。音色一人一号：只有给某位 TA 绑过 voice_id，对方文字消息旁才出现小喇叭，没绑的 TA 不显示播放按钮，也不会拿别人的声音或全局默认念出来。群聊里按每条消息的署名找同名联系人，谁说的就用谁的音色，查不到本人同样不显示。绑音色与试听都在聊天页右上角 →「TA 的声音」；接口地址、API Key、账户组与语速在这一格填。念错了、或者这个音色念某句怪：**长按那条消息旁边的小喇叭**就会丢掉这句的存档重新合成一遍（同一段话＋同一音色只存一份，念错就一直重放同一段）。合成的语音会自动存进该联系人专属的字卡库（字卡库 → 专属字卡 → 「语音」分类下的「XX的语音」分组），同一段话同一音色只在第一次点播时请求接口，之后直接播库里的存档。

每枚上面的小样就是它套上去的长相：清爽＝直角、实心白、什么都不糊；柔和＝卡片调圆、仍是实心白；磨砂＝卡片变半透并把背后糊开（小样里那层斜纹就是「背后」，真实桌面是壁纸或底色）；沉浸＝磨砂再加上聊天气泡也糊、壁纸再模糊一档。⚠ 后两档的差别有一半在聊天页（气泡）和配了壁纸的时候才看得见，光在外观这一页点，磨砂与沉浸的卡片观感是一样的。套完仍可去下面各卡单独微调；当前各项与哪套逐字吻合，那一枚就描边；手改过则都不描边。

取景

「模糊」把壁纸本体糊开（0＝不糊）。单独用只在卡片缝隙里看得出一层软；配「卡片通透」（设置→外观）开时最明显——壁纸透到磨砂卡片后面，与卡片那根磨砂强度各糊一层、可叠加。

底下那一行导航条压在这张图上要露多少：0＝完全透出壁纸，100＝与不挂图时一样实。

弧度

管的是卡片、列表行、磁贴、底部弹层这些面的弧度，三档都是整屏一起换。「利落」接近直角、屏面最硬；标准是默认；「柔和」最圆。聊天气泡与头像不跟这一档（它们各有自己的形状档）。

宽屏布局

在 iPad 或电脑浏览器上，本站默认把内容放宽成一栏（约 820px）用好大屏。想回到手机那种窄窄的一屏（480px 居中卡片），把上面切到「手机窄栏」即可。手机本身不受影响（本来就是窄栏）。点一下当场生效、重启仍记得。

形状

全站头像一起换形状（会话列表、聊天气泡旁、信箱都算）：圆形／圆角／方形，点一下立即生效、重启仍在。

进阶功能：懂 CSS 再写，只作用于这一位 TA 的气泡（也可点「选择 .css 文件」把一份 CSS 读进来）。常用类名：.message 一条消息（加 .mine 是我方）· .bubble 气泡 · .mini-avatar 小头像 · .ft-time 时间小字（#559 起与情绪词同在 .foot-line 那一行）· .day-label 日期签——别的工程（如 mochi）的类名在这打不中，得按上面这套重写。写好的样式整段自动加权，盖过配色（含对方气泡底色）与形状档位，不用再手写 !important；以 .bubble 收尾的那条会自动绕开两张互动卡（问问TA · TA 想问你——它们卡面永远走中性白，写成黑底白字会把卡里的字糊掉），要单独定制那两张就直写 .ask-card · .taask-card，不想绕开就把上面那一枚勾上；@keyframes 里的动效也能正常写。写错不生效也不会弄坏页面，清空即可回头。以 body／:root 开头的写法（例如 body .ft-time{…} 或 :root{--mine:…}）同样自动加权——它们也只作用于这一位 TA 的聊天页，不会被深色壁纸那批自动翻白规则压掉。

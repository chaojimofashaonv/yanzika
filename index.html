它是怎么工作的（点开看）

音色一人一号：只有给某位 TA 绑过 voice_id，对方文字消息旁才出现小喇叭；没绑的 TA 不显示播放按钮，也不会拿别人的声音或什么「全局默认」来念。群聊里按每条消息的署名找同名成员，谁说的用谁的音色，查不到本人同样不显示。

念错了、或者这个音色念某一句怪：长按那条消息旁边的小喇叭＝丢掉这句的存档重新合成（同一段话＋同一音色只存一份，念错会一直重放同一段）。合成结果自动存进该联系人的专属字卡库（字卡库 → 专属字卡 →「语音」下的「XX的语音」），同一段话同一音色只在第一次点播时请求接口，之后直接播存档。

游戏中出声只在有结果的一刻响：合上了、消掉了、推倒了、这一局结束了。滑动、点选、落子这些「每一下」不出声
音量拖到 0 就彻底无声。这一格只记在这台设备上，不随备份导出带到别的手机里

这一格只管小游戏里的声音，是这台设备的一份开关（不分联系人，也不随备份带到别的手机）。TA 发来消息 ∶ 我发出消息 ∶ 来电振铃那三种提示音是按人各一份，在聊天页右上角 → TA 的设置 → 声音 → 提示音 里改——两件事的归属不同，所以没并在一起。

每枚上面的小样就是它套上去的长相：清爽＝直角、实心白、什么都不糊；柔和＝卡片调圆、仍是实心白；磨砂＝卡片变半透并把背后糊开（小样里那层斜纹就是「背后」，真实桌面是壁纸或底色）；沉浸＝磨砂再加上聊天气泡也糊、壁纸再模糊一档。⚠ 后两档的差别有一半在聊天页（气泡）和配了壁纸的时候才看得见，光在外观这一页点，磨砂与沉浸的卡片观感是一样的。套完仍可去下面各卡单独微调；当前各项与哪套逐字吻合，那一枚就描边；手改过则都不描边。

预设是内置的六款天光（晨雾／宣纸／远山／苔原／奶咖／石白），点一枚就用，不用去相册找图。只有一条极缓的明暗与两枚柔光，没有图形也没有纹路，所以放到大屏也不糊、也不会压过页面上的字。六款都不垫纱也不压暗（它们本来就是浅到能直接压墨字的一族，垫一层白或压一层黑都只会把它抹平），点一枚就是它本来的样子；上一张自传照片留在「压暗／提亮」两根杆上的值会被这两档一起归零。缩放、取景、铺到哪几页对预设同样生效；选了自定义照片后，预设自动让位。

其它页面

上面四枚可多选：勾上哪页，这张图就透在哪页的卡片缝里（没选图时都不起作用）；四枚全不勾＝哪页都不铺，图还在。「其它页面」＝信箱·设置·统计·收藏·朋友圈·播放器·游戏这些不走底部导航的页。

「提亮」给壁纸垫一层白纱——照片太花、铺开之后页面上的字看不清时往右拖，垫到五六成整页都读得出，壁纸退成一层柔色。自传照片时按这张图自己的暗端自动定档（浅图 0~45%、深图与花图 80% 上下——那一档照片会明显退成柔色，这是「字要读得出」的代价），之后随你拖。「压暗」是另一头的口味：往黑里压，对墨字可读性是反方向（压得越多、字越难读），只在想要暗调时用。内置六款预设两样都不吃（点预设会归零）。

取景

「模糊」把壁纸本体糊开（0＝不糊）。单独用只在卡片缝隙里看得出一层软；配「卡片通透」（设置→外观）开时最明显——壁纸透到磨砂卡片后面，与卡片那根磨砂强度各糊一层、可叠加。

底下那一行导航条压在这张图上要露多少：0＝完全透出壁纸，100＝与不挂图时一样实。

界面玻璃 · 自由美化壁纸铺到哪页就管哪页的白卡

只管【TA 主动】发来的消息：你发一句之后他的回话、你寄出去的信到站、纪念日开口都不在这条链上。不让他主动来电那一格在「声音 → 通话」里（那一枚另有按人一份的开关，不并进这一枚＝解除免打扰时没法还原他原来那一档）。与「夜间免打扰」也不是同一件事：那条按时间窗（23:00–07:00）全站拦，这一条按人长期拦，两道同时在场、任一命中都不掷。

多久开口一次

这一格动的是【间隔】，不动上面那格「主动概率」：TA 空闲时等得最短，忙碌、休息、睡着依次更长；同一档里还分「在做什么」——忙着贴着你比手上真有事短得多，「装着忙等你先找我」反而等得更久（可他一看到你的消息就回），具体那行字写在世界感知「此刻」卡上。开着上面「拉长间隔」时本来就要等 1~3 小时，这一族基本看不出来。它调的是【多久】，与设置 → 提醒 里那条按时间窗硬拦的「夜间免打扰」不是同一件事。

开口说给谁

到点开口时先掷这一格：中了就把那几句说给他所在的群（几个群之间均分，多一个群就每个群少一点），没中就是说给你。填 0＝他从不在群里自己冒话。群本身没有一条钟——这张卡里每一格都只属于「某一位联系人」：在他单聊那一屏改、或在群里选中他改，动的是同一份。停在「本群」那一档时整张卡收起（BUGS #216＝群没有自己的钟，摆在那里改了不动任何东西）；群里选中某位时读写的也正是他自己那一份（BUGS #1728＝成员档原先读写的还是本群那份，两位成员看到同一组数）。

填了这位 TA 才有自己的声音：对方文字消息旁出现小喇叭，点它就按这枚 voice_id 朗读，合成的语音自动存进 TA 的专属字卡库。留空则这位的消息不显示播放按钮——不会借用别人的音色，也没有全局默认可退。API Key 在「设置 → 玩法 → MiniMax 语音」里填（#1083 起那格正面就一个 Key，账户组／地址／模型／语速都收进了「高级」）。

# 言字卡

传讯网站：**字卡传讯**、字卡库、写信信箱、世界感知，全部数据存在你自己浏览器里，没有后端、没有云，默认不发网络请求（除已有 Service Worker）。**本站不是 AI 聊天**：回复由纯代码完成——从系统内置字卡和你自己上传的字卡里挑一张随机发出来，不是 AI 生成的，也没有接入任何大模型。仅个别功能要你自己开启并填入密钥／链接后，才会向对应的第三方发请求——例如 MiniMax 语音（接入第三方开放平台、自备 API Key，非本站自带的能力）、网易云歌单链接，详见 [LICENSE](LICENSE)。

## 怎么用

- 直接双击 `index.html` 就能跑：页面片段内联，样式与脚本引同目录的 `dist/app.v<版号>.css` 与 `dist/app.v<版号>.js` 两件（两个文件在同一份交付里，别只拷 `index.html`）。
- 部署成静态站点时，连 `sw.js` 一起发布，PWA 与离线缓存才生效（Android 壳与出包链路已于 2026-10-22 整体退役）。
- 换机或重装前先「设置 → 数据 → 导出全部数据」，回来导入即可，数据不会丢。

## 仓库里有什么

这个仓库（`yanxu233/jinzhierchuanyanzika`，部署用）只有跑站所需的交付件：

| 路径 | 是什么 |
| --- | --- |
| `index.html` | 薄入口：页面片段内联，引下面 `dist/` 两件，双击即用 |
| `dist/app.v<版号>.css` `.js` | 两份合并件，**未压缩、可直接读改**：按版本号把源件拼死，文件名带版号＝缓存键随版本走 |
| `img/` | 字卡牌面与素材 |
| `sw.js` `manifest.json` `version.json` `asset-manifest.json` | Service Worker、PWA 清单、版本号、本版交付件清单 |
| `icon.svg` `icon-*.png` `apple-touch-icon.png` `_headers` `.nojekyll` | 图标、静态托管的缓存头、跳过 Jekyll |

拆分源件（`css/` `js/` `html/` 一功能一件）与组装器（`tools/assemble.py`、回归哨兵 `tools/check_fixes.py`）在作者的开发仓，不随这个部署仓发布。

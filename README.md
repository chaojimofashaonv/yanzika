# 言字卡

纯前端私人聊天 PWA：虚拟伙伴对话、字卡库、写信信箱、世界感知，全部数据存在你自己浏览器里，没有后端、没有云，默认不发网络请求（除已有 Service Worker）。仅个别功能要你自己开启并填入密钥／链接后，才会向对应的第三方发请求——例如 MiniMax 语音（接入第三方开放平台、自备 API Key，非本站自带的能力）、网易云歌单链接、B 站外链播放器，详见 [LICENSE](LICENSE)。

## 怎么用

- 直接双击 `index.html` 就能跑：页面片段内联，样式与脚本引同目录的 `dist/app.v<版号>.css` 与 `dist/app.v<版号>.js` 两件（两个文件在同一份交付里，别只拷 `index.html`）。
- 部署成静态站点时，连 `sw.js` 一起发布，PWA 与离线缓存才生效（Android 壳与出包链路已于 2026-10-22 整体退役）。
- 换机或重装前先「设置 → 数据 → 导出全部数据」，回来导入即可，数据不会丢。

## 仓库里都有什么

| 路径 | 是什么 |
| --- | --- |
| `index.html` | 组装产物：薄入口（片段内联＋引下面 `dist/` 两件），双击即用 |
| `dist/app.v<版号>.css` `.js` | 组装产物：源件按清单拼成的两份合并件，文件名带版号＝缓存键随版本走 |
| `index-module.html` | 开发调试入口：CSS 外链、改 css 存盘刷新即生效 |
| `css/` `js/` `html/` | 源码，一功能一件；**只改这里** |
| `assemble.json` | 组装清单（加载顺序＝插拔开关） |
| `tools/assemble.py` | 组装器：拼两份产物，顺带三道闸（清单与磁盘对应／语法可解析／产物与源一致） |
| `tools/check_fixes.py` | 回归哨兵：逐条核对历史修复还在不在 |
| `AGENTS.md` `文档/` | 给 AI 与维护者看的协作说明；模块表·数据结构·协作日志在 `文档/` 下 |
| `sw.js` `manifest.json` `version.json` `icon*.svg` `icon*.png` `apple-touch-icon.png` | PWA 清单、Service Worker、图标与版本号 |

改完源文件跑 `python tools/assemble.py --bump`（版本号三处 +1 并派生 `version.json`），再跑 `python tools/check_fixes.py`，两者退出码 0 才算完成。设计稿·对比稿·预览页·本机快照·打包中间物一律不进本仓库。
